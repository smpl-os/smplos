# Hyprland packages smplOS holds back while Arch ships a Hyprland series that
# smplOS has not validated yet (see HYPRLAND_SERIES in critical-bundle.conf).
#
# Normally nothing is held: smplos-update upgrades the whole system, the
# Hyprland stack included, in ONE pacman transaction. Holding hyprland while
# Arch rebuilds its libraries against new sonames is a partial upgrade: it
# fails (`installing aquamarine (0.15.0-2) breaks dependency
# 'libaquamarine.so=12-64' required by hyprland`) and blocked every system
# update for a month in 2026. Only a new, unvalidated series is held, and if
# other packages already require it the update reports that it waits for
# smplOS to validate the series instead of installing a broken mix.
#
# Keep one package per line. No commas.

hyprland
xdg-desktop-portal-hyprland
